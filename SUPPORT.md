# Getting Support

Need help using Open Food Facts, integrating with our API/data, or setting up a local development environment? Please use the channels below instead of opening a bug report for general questions.

## Community & Developer Channels

- **Slack (fastest for contributors & developers):** Join [slack.openfoodfacts.org](https://slack.openfoodfacts.org/) and ask in the relevant project channel (e.g. `#api`, `#smooth-app`, `#robotoff`, `#documentation`, or `#general`).
- **GitHub Discussions:** If the repository has the **Discussions** tab enabled, use the Q&A category to ask questions so answers remain searchable for others.
- **Open Food Facts Wiki:** Browse [wiki.openfoodfacts.org](https://wiki.openfoodfacts.org/) and the [Tech Team documentation](https://wiki.openfoodfacts.org/Tech_Team) for guides, architecture notes, and FAQs.

## Data & API Questions

- Explore the [Open Food Facts API documentation](https://openfoodfacts.github.io/openfoodfacts-server/api/) and [open data resources](https://world.openfoodfacts.org/data).
- For research collaborations, data reuse questions, or general inquiries, contact **`contact@openfoodfacts.org`**.

## Security Issues

**Do not** report security vulnerabilities in public issues, discussions, or Slack. See our [Security Policy](https://github.com/openfoodfacts/.github/blob/main/SECURITY.md) for private reporting instructions.
